# 炫采外牆有限公司｜SKYWORKS 官網部署說明

## 一、檔案內容

- `index.html`：網站主程式，包含繁體中文文案、RWD 響應式樣式、互動功能及 SEO 基本設定。
- `assets/`：由本次提供的品牌識別與 11 頁品牌簡報整理的圖片、圖示素材。
- `robots.txt`：搜尋引擎爬取規則。

本網站為**單頁式靜態官網**，不需要安裝 WordPress、資料庫、Node.js 或額外套件。HTML、CSS、JavaScript 均已備妥。

## 二、立即使用

1. 解壓縮本 ZIP。
2. 保持 `index.html` 與 `assets` 資料夾的相對位置不變。
3. 用 Chrome、Edge、Safari 開啟 `index.html` 即可預覽。
4. 佈署至網站主機時，把 `index.html`、`assets` 與 `robots.txt` 一起放到網站根目錄（例如 `public_html`）。
5. 若使用 Netlify／Cloudflare Pages 等靜態網站服務，可上傳整個網站資料夾。

若只想要一個可直接開啟的網頁檔案，另提供 `炫采外牆_單檔版_可直接開啟網站.html`，所有圖片都已內嵌。

## 五、正式上線前建議

1. 設定正式網域與 HTTPS。
2. 在已購買網域後，新增 canonical URL 與絕對網址的 `og:image`，可使用隨附的 `assets/og-cover.webp` 做為社群預覽圖。
3. 確認營業地址、電話、服務範圍與最新公司資料。
4. 換上取得授權的**實際施工案例照片**，並為每個案例補充所在區域、工法、施工前後說明及授權狀況。現有圖片為品牌簡報中的情境影像，網頁已明確註記非實際完工案例。
5. 若要加入線上詢價表單、寄送 Email、客戶資料蒐集或 CRM，需要另外設定後端／表單平台、個資告知與資安控管。**目前沒有假裝可傳送的表單。**
6. 為搜尋排名持續更新真實案例、常見問題、區域服務頁及 Google 商家檔案。
7. 如需客戶追蹤、線上預約、線上報價系統，建議後續再擴充。
